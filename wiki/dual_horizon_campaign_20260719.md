# 5D and 10D need native labels

A holding period is an execution choice; it does not by itself make a factor a
5D or 10D factor. The evolution objective must use the matching forward return.
For a frozen panel, labels must be recalculated within each split so no return
crosses the train/validation/test boundary.

The 30-round campaign keeps the 5D and 10D lineages independent. Validation
Sharpe governs whether a candidate becomes the next research seed; test values
are recorded but not used in that decision. This changes repeated evolution
from test-set hill climbing into a reproducible selection experiment.
