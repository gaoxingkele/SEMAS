# 时辰校准案例分析

本目录用于“出生年月日较可靠、出生时辰不可靠”的公众人物案例校准。它不证明真实出生时辰，只比较十二个候选时辰中，哪一个更能解释公开可核验的人生事件序列。

## 当前架构

1. 固定出生年、月、日和出生地。
2. 按十二时辰生成 12 份候选命盘。
3. 每个候选命盘作为一个“时辰候选子智能体”独立分析。
4. 八字作为主判系统，负责四柱、五行、流年、刑冲合害和事件类型标记。
5. 紫微斗数作为辅助系统，负责命宫、身宫、十二宫主题和流年宫位。
6. 星座学作为辅助系统，负责太阳、月亮、上升、年度宫位和年度触发星。
7. 汇总 12 个候选子智能体的逐事件得分，输出排序、领先幅度、分歧状态和证据说明。

## 目录约定

- `cases/`：案例输入。每个 JSON 是一个公众人物。
- `outputs/`：运行后的候选盘、评分表和结论。
- `hour_calibration.py`：本地可执行评分脚本。

## 输入事件要求

- 必须有明确年份。
- 必须标注事件类型，例如学业、事业、权力、财务、婚恋、家庭、子女、迁移、健康、丑闻、公众声望、死亡等。
- 必须记录来源字段。来源可以是百科、官方资料、论文、新闻、传记页码或人工整理说明。
- 重大公众人物案例要同时覆盖顺境和逆境，不能只放成功年份。

## 评分边界

- 如果第一名领先不明显，输出“模糊”，不能强行锁定时辰。
- 公开资料中的常见时辰要和算法拟合结果分开记录。
- 传闻事件不能和确定事件同权重。
- 紫微和星座当前是辅助交叉验证，不替代八字主判。
