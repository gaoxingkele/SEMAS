# 七个传统八字流派 AHP 吻合度对比 2026-07-08

## 统计口径

本轮把七个八字流派都转成 AHP 层次票。对 11 个公众人物案例，每个流派都独立给 12 个候选时辰排序，然后看公开参考时辰在该流派下排第几。

指标说明：

- 平均参考排名：越低越好。
- 第一数：公开参考时辰被该流派排第 1 的案例数。
- 前三数：公开参考时辰被该流派排进前 3 的案例数。
- 平均参考分：公开参考时辰在该流派下的平均分。

## 解释

子平真诠排第一，说明“格局成败、用神清纯、破格救应”这条线对公开参考时辰的平均解释力最好。

三命通会排第二，但前三数最高，说明综合古法的广谱检查能覆盖更多候选，不容易漏，但也可能因为规则太宽而不够尖锐。

横门断排第三，仍然稳定。它的优势是强断和事实筛选，适合公众人物案例，但在政治人物和复杂人生主线上还需要大运、调候、病药补充。

穷通宝鉴排第四，说明调候法有价值，尤其适合解释状态、健康、学业、发挥环境。但它不应单独决定事业名望。

渊海子平平均分最高，但平均排名不高，说明它给参考时辰的分数不低，却没有很好拉开候选差距。

滴天髓和神峰通考当前排名靠后，主要是因为现有事件只有年份，没有足够细的月份、身体状态、危机链和转折过程。气势流通和病药法需要更细的事件材料。

## 七派之外的传统八字方法

八字传统不止七派。当前七个是“以古籍为核心的子智能体”，但还应继续扩展这些方法：

| 方法 | 作用 | 是否已独立成 skill |
|---|---|---|
| 早期禄命纳音派 | 年命、纳音、禄马贵人 | 否 |
| 神煞派 | 桃花、驿马、华盖、羊刃、天乙等 | 否 |
| 盲派象法 | 宫位、宾主、做功、穿倒、直断事件 | 否 |
| 宫位六亲派 | 年月日时对应祖上、父母、自己婚姻、子女晚年 | 部分内置 |
| 刑冲合害穿破派 | 专看地支作用和事件触发 | 部分内置 |
| 旺衰扶抑派 | 身强身弱、扶抑泄耗 | 部分内置 |
| 从格专论派 | 从财、从杀、从儿、从旺等 | 否 |
| 化气格专论派 | 甲己合土、乙庚合金等化气格 | 否 |
| 岁运应期派 | 大运定阶段，流年流月定触发 | 部分内置 |
| 现代新派量化派 | 量化旺衰、喜忌、组合打分 | 部分内置 |

## 下一步

1. 把盲派象法、神煞派、纳音派、旺衰扶抑派拆成独立子智能体。
2. 给每个流派建立独立 AHP 权重和事件适用范围。
3. 不同人物类型采用不同权重：政治人物、影视演员、歌手、商业人物、学生不能共用一张权重表。
4. 事件需要加入月份和日期，尤其是健康、婚姻、丑闻、获奖、票房、升迁。
