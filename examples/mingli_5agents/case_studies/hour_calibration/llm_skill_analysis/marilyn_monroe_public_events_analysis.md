# Marilyn Monroe（marilyn_monroe_public_events）十二时辰校准分析报告

> 分析日期：2026-07-28。方法：知识库技能驱动的十二时辰校准。

## 1. 三柱共性定盘（丙寅 / 癸巳 / 辛酉）

### 1.1 月令取格（横门·第十二章「用神专求月令」）

- 月令巳，藏丙（本气）、戊、庚。丙火本气**透年干**（丙寅），按「谁透用谁」
  取**正官格**；官星丙火坐寅长生、通根月令，官星有力。
- 官星透于**年柱**：横门「年上朝廷」（第二十三章），官在年主公家、全国性乃至
  世界级层面的名分——与「全美国最受瞩目的名人之一」（1954）量级吻合。这是
  三柱共性，12 个时辰共享，不构成区分度，但约束了格局主线：此命的「事业最高
  点」由正官名气兑现，而非财格巨富。

### 1.2 日主强弱与病药

- 辛金坐酉为**临官禄地**；巳酉**半合金局**（缺丑），日主得地得势，中和偏旺。
- 巳月丙火司权，夏金受克；月干**癸水食神**高透，紧邻年干丙火——表面是
  「官逢伤克」之败（横门·成败救应），需要救应。
- 但事件表给出决定性反证：**1952 壬辰（伤官透）、1953 癸巳（食神透）连续两年
  食伤透干，恰是事业大爆发期**（权重 1.0 + 1.5）。若食伤是破格忌神，透干之年
  应凶。故正解是：此造身不弱，**癸水食神是泄秀+调候的双重喜用**，不是破格之字；
  演艺才华（食伤泄秀）与公众魅力正是靠它兑现。横门「事实校准」原则（案例十五：
  多解并存时取更容易兑现者）支持这一取舍。

### 1.3 调候主线（穷通宝鉴·辛日巳月）

- 「**壬水淘洗兼调候，甲木制戊，一清彻底**」：巳月辛金以壬水为第一调候用神，
  忌火土燥热熬干水源。
- 三柱癸水透而**无根**（巳寅酉中皆无水），如朝露入火——调候能否落实，完全
  取决于时柱是否补水之根。**这是逐时辰裁定的第一权重**。

### 1.4 夭寿伏笔（滴天髓《何知章》：夭看「气浊神枯」）

- 36 岁早逝（1962，权重 1.7）。三柱自带隐患：火旺于夏、水源孤悬；凡时柱
  再添火土（戌、未、午）者，火炎土燥、金水被熬，夭象加重；凡时柱补水者，
  金水相涵，结构清而长寿之基——但事实是她早逝，故补水时辰须另有凶运触发
  机制（寅刑巳提纲、伤官见官、三刑齐全等）方能解释 1962。

### 1.5 共性神煞（命理集成神煞索引，不区分时辰，仅备参）

- 辛酉日：**阴差阳错煞**（第三十一节）、**八专**（第三十三节，主淫慾）、
  **红艳煞**（辛见酉，第二十八节，女命最忌主多情）——婚姻屡挫、性感偶像、
  私生活复杂的象，三柱已足，12 时辰共享。

- 高峰年（52/53/54）= **水（食伤）与火（官）同被引动** → 时柱须让「金水相涵、

  争合则多夫。
- 低谷与死亡（61/62）= 金局争官、提纲被刑、伤官见官 → 时柱若自带与寅、巳
  相关的刑冲结构，1962 的解释力大增。

## 4. 完整排序与前三名把握度

**辰 ＞ 申 ＞ 巳 ＞ 亥 ＞ 子 ＞ 酉 ＞ 卯 ＞ 丑 ＞ 午 ＞ 寅 ＞ 未 ＞ 戌**

1. **辰时（壬辰）——把握：高**
   - 穷通宝鉴辛日巳月主用「壬水淘洗」唯一透干且得库根落实的时辰，金白水清。
   - 金水伤官见官合横门「官伤不并透、财印为辅」之成格条件，名气（官）与才华
     （伤）两不碍。
   - 1952 壬辰伏吟引动喜用应爆发、1962 壬寅伤官见官 + 寅刑巳提纲应死，头尾
     两个高权重事件双双命中。
2. **申时（丙申）——把握：中**
   - 壬水长生调候有源；原局巳申刑埋伏，庚寅运 + 壬寅年补全**寅巳申三刑**，
     1962 死亡应期机制全场最精确。
   - 双丙正官争合日主，精确对应两任名人丈夫（1954/1956 官星透合年）。
   - 亡神临时（集成第二十三节）与 1961 精神崩解同向；略逊于辰者：壬水不透、
     官星坐劫地、丙火官星透时为「引动归时」主名分兑现偏晚偏小，与实际巅峰
     在 26-28 岁略有出入。
3. **巳时（癸巳）——把握：中**
   - 双癸并透、双巳官禄，「双柱同功」象大，世界级偶像的量级解释力最强；
     1953 癸巳流年叠引应巅峰。
   - 火炎水枯（癸双透无根）+ 寅刑双巳，1962「气浊神枯」夭象顺。
   - 硬伤是调候不落实（无壬水根），秀气虚浮，故列第 3 而不敢进前 2。

总体把握度说明：横门案例十五明言时辰未知「三柱看也是可以的，时柱只细化档次
与应期」——12 个时辰共享三柱主线，彼此区分度天然有限；前三名差距在「调候
落实度 × 应期机制精确度」，故前三名给 高/中/中，整体判断为**中等把握**。
