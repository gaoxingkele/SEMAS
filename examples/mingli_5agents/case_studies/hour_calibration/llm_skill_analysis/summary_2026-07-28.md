## 关键发现

1. **知识库分析是三种方法中最强**（3.64 / 3 / 8），且失败案例与确定性方法互补：
   知识库修好了 Oprah（11→2）、Obama（12→4）、Monroe（4→3）、MJ（2→1）、
   Bruce Lee（5→3），只在 Trump（3→12）和 Hepburn（8→8 持平）上不占优。
2. **互补即机会**：两法并集前三覆盖 9/11 案例；逐案例取三者最优平均排名
   2.64。下一步方向：等权融合与知识库分析的两级级联（先等权取候选集，
   再知识库精读裁决），而不是二选一。
3. **知识库的独特价值在可解释性**：每个排名都带落到典籍规则的推理链
   （如 Mao：双甲夹丁化杀 + 两戌年冲辰应迁移 + 丙辰伏吟应寿终；
   MJ：1982 壬戌 Thriller 年与时柱干支全同伏吟）。确定性管线只给分数。
4. 知识库分析者自主发现了「事件表反推喜用再校时」的方法论
   （Trump 例：1983 财年大成 + 1991 比劫年破产 → 财星为喜用 → 补水时辰居上），
   这是 AHP 固定权重做不到的。

## 诚实边界

- **污染风险不可排除**：11 例均为公众人物，参考时辰印在简报首部；
  分析者声明未使用且多例把参考列在末位/中游（Trump 12、Bruce 11、
  Hepburn 8）可佐证未被牵引，但无法证明零潜意识影响（MJ 分析者原话）。
  确定性管线在构造上无此风险。因此知识库结果应读作「上限估计」。
- 每案例单次运行，无方差估计；排名对 prompt 与模型状态敏感。
- 简报附带了管线分数供对照（声明为仅供参考），多数案例排名与管线
  分数明显分歧，说明分析者主要依赖知识库推理而非抄管线答案。
- 参考时辰本身为公开传闻级证据（Obama/Oprah/Hepburn 的可靠性此前已存疑），
  「与参考不一致」不等于分析错误。
