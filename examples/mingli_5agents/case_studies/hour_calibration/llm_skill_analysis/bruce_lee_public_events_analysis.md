# Bruce Lee（bruce_lee_public_events）十二时辰校准分析报告

- 分析依据：仅以简报事件表 + 干支推理 + 知识库规则。分析全程未使用简报中的公开参考时辰，亦未调用对该人物八字的任何先验记忆（污染声明见文末）。
- 使用技能：`mingli-bazi-hengmen`（月令取格、成败救应、引动归时，主裁）、`mingli-bazi-qiongtong-baojian`（调候）、`mingli-jicheng`（神煞与格局索引，侧证）、`mingli-bazi-ditiansui`（寒暖燥湿、寿夭）、`mingli-bazi-sanming-tonghui`、`mingli-xingping-huihai`（辅助）。

## 一、三柱共性（庚辰年 / 丁亥月 / 甲戌日，男）

- **旺衰**：甲日主生亥月，亥为甲木长生、月支得气；年支辰中乙木余气为微根；庚杀透年干贴克，丁伤透月干泄身。整体中和偏弱、偏于寒湿，时柱对身强身弱与寒暖的拨动极大——这正是本案时辰分辨的核心杠杆。
- **月令取格（横门第十二章）**：亥本气壬水偏印当令不透，按"月令无用神、看透干会支另取"的建禄/长生月劫类处理：年透庚杀、月透丁伤，主线为**杀、伤并用**——"伤官制杀"能否成立、以及调候火是否有根，是格局成败的关键。
- **调候（穷通宝鉴·甲木亥月）**："用庚，取丁制庚，丙调候；水旺用戊。"原局庚、丁皆透，已具"丁制庚"的骨架，但**丙不见**（寅、巳、午可补）、丁自坐亥水截脚、仅靠戌中丁火微根——时柱能否补火暖局或补戊制水，直接决定调候成败。
- **神煞共性**：年支辰（申子辰）驿马在寅、劫煞在巳、亡神在亥（月支自带亡神，主机关不宁）；日支戌（寅午戌）驿马在申、华盖在戌（艺术、孤高）。甲日天乙贵人在丑未。
- **寿夭总纲（滴天髓《何知章》）**：夭看"气浊神枯……金寒水冷或火炎土燥"；横门第二十章：健康寿夭看**阳刃无制**与刑冲穿破落宫。本案有 1973 年暴卒（权重 1.7），时柱自带"贵气+一处致命破绽"者优先。
- **大运估算（仅作辅助）**：阳男顺排，月柱丁亥 → 戊子、己丑、庚寅、辛卯……按出生至大雪约 10 天估 3 岁余起运，则 1966–1973 年（含去世）大体行**庚寅运**：庚杀再透攻身、运支寅与命局形成拱合/伏吟。起运岁数为估算，不用于硬性加减分。

## 四、排序与前三名理由

**完整排序（优 → 劣）**：
寅时 ＞ 卯时 ＞ 辰时 ＞ 申时 ＞ 未时 ＞ 午时 ＞ 戌时 ＞ 巳时 ＞ 酉时 ＞ 子时 ＞ 丑时 ＞ 亥时

### 第 1 名：寅时（把握度：中）

1. **格局最清、调候全到位**：甲禄在寅身旺任杀，丙火透时正补穷通宝鉴亥月甲"丙调候"之缺；寅戌拱午按横门"拱局可立格"（第二十三章）成立食伤吐秀之局，是十二局中唯一"调候 + 立格 + 旺度"三者同时闭环的时辰。
2. **应期链最顺**：1959 己亥合动驿马（寅）而迁美；1966 丙午恰好**填实寅戌所拱之午**而大红；1973 癸丑流年癸盖头克丙——**食神寿元星被夺** + 丑戌刑，暴卒应期干净；庚寅运运支与时支伏吟再添一重凶险。
3. **神煞贴合生平**：驿马在时（申子辰马在寅），正应其横跨美、港两地奔走成名的一生。

### 第 2 名：卯时（把握度：中）

1. **人象贴合度最高**：阳刃 + 伤官双透制杀（穷通宝鉴亥月甲明言"取丁制庚"），刃伤格局主武艺、刚烈、破旧立新——与武术家兼革新者的人生轨迹同构；卯戌合火使伤官成局、调候得暖。
2. **寿夭破绽明确**：庚杀被双丁夹克太死，**阳刃无制**——横门第二十章与集成羊刃条（"身强遇刃灾祸勃然"）同指此为主暴卒之征；1973 癸丑癸夺丁伤、丑戌刑，引动到位。
3. 减分项：杀被制太过、官星路线全废，富贵层次略损，且 1971–72 水年生刃寒局的解释稍牵强，故居第二。

### 第 3 名：辰时（把握度：低–中）

1. **1973 应期层次最多**：流年癸与时干戊**戊癸合（制水用神被合去）** + 丑戌刑 + 丑辰破，原局双辰冲戌的日时根基冲战被全面引动，土崩水泛而殁，事件链完整。
2. **调候有得有失**：戊透正应穷通宝鉴"水旺用戊"，但辰戌冲伤及戌中丁火微根，格局仅中平（印格透财之嫌），富贵解释力逊于寅、卯。
3. 减分项：1959 迁动、1966 吐秀两年应期平淡，主要靠 1964（辰辰自刑冲戌）与 1973 两年硬事件支撑，故把握度偏低。

### 落选说明（第 4–5 名）

- **申时**：杀印相生 + 驿马在时 + 官印年入学都很顺，惜丁壬合灭暖火、1973 应期偏弱。
- **未时**：1973 丑戌未三刑全会日时是全场最硬的单年证据，且有天乙贵人，但伤官见官、官杀混杂令格局浊，富贵期应期全面平淡，按横门"格局成败为主线、应期为辅"的口径只能列第五。
