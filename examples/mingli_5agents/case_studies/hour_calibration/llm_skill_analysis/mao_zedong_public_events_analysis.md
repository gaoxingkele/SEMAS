## 一、三柱基线（所有时辰共享）：癸巳 / 甲子 / 丁酉，男

### 格局主线（横门·月令取格）
- 日主丁火，生于子月，癸水司令。**月令子水为七杀，癸透年干 → 七杀格**（"八字用神，专求月令"，第十二章格局开篇）。
- 月干甲为正印：**杀印相生，以印化杀**，是逆用七杀的控制性使用；印为相神，全局枢纽在甲。成格关键：印不可伤（财坏印即破格），杀不可混杂（壬官再透则官杀混杂）。
- 日主身弱：丁火仲冬失令，仅通根年支巳（巳中丙，且巳落空亡——丁酉属甲午旬，辰巳空），日坐酉为丁火长生（阴干长生），弱而有生意。
- 喜忌：喜木（印）、火（比劫帮身）；忌金（财坏印党杀）、忌水过旺、忌壬官混杀。
- "年上朝廷"（横门第二十三章术语）：癸杀透于年干，象在朝廷/国家层面，与一生事业规模相符。

### 调候（穷通宝鉴）
- 子月丁火：同亥月，"庚金劈甲引丁，**甲为尊，庚为佐**，戊癸权宜酌用"。甲已透月干；时柱再见甲（得尊神双透）为上，见庚为佐次之。

### 神煞基线（命理集成，以年支巳/日支酉，巳酉丑组）
- 日支酉：天乙贵人（丙丁猪鸡位）、文昌（丁己酉）、将星（巳酉丑见酉）——日坐三贵，主权柄与文华，各时辰共享。
- 天德：子月天德在巳——年支巳带天德，各时辰共享。
- 空亡：甲午旬辰巳空——年支巳空；**若时支为辰，则时柱亦空**（子女宫空、水库杀库空）。
- 琴堂虚实法（星平会海卷一）："吉空则凶，凶空则吉"——辰为水之库（杀之库），杀库空属"凶空则吉"，杀威收而不自伤。

### 大运（阴年男，逆排，约 6–7 岁起运，供应期参考）
癸亥 → 壬戌 → 辛酉 → 庚申 → 己未 → 戊午 → 丁巳 → 丙辰（约 1970–1980）。

## 二、事件应期校验要点（用于加减分的高权重事件）

以杀印格喜忌 + 横门"引动"（运/流年与命局同气即加强该字之象）逐条对表：

- 1927 丁卯（权重1.1，受挫转向）：卯冲日支酉，自身根基受冲而迁移，各时辰同论。
- 1930 庚午（1.1，妻亡）：庚财克甲印（庇护之星受伤）+ 午冲子（提纲逢冲）——印被财克之年应家庭剧变，格局逻辑一致。
- 1934 甲戌（1.4，长征迁移）：甲喜神透而戌动土局。**辰时：戌冲时支辰，时柱（归宿）逢冲 = 大迁移，精确命中**；1958 戊戌（1.2，大跃进）再冲辰，两次戌年两次大运动，重复性极强。
- 1935 乙亥（1.3，掌权）：偏印喜神透年，印化杀得权，各时辰合。
- 1943 癸未（1.1，权威集中）：癸杀引动年干，未为丁之羊刃（集成第二十七节：丁己未，"煞刃两停反贵"）——杀刃之年权力上升，合。
- 1945 乙酉（1.2，思想确立）：印透 + 文昌将星流年，"印 = 思想学说"之象，合。
- 1949 己丑（1.6，建国）：己食神制杀（横门七煞格首成"食神制煞"），丑合子（月令用神被合住 = 杀为我所制），杀受制而身登其位，格局逻辑通顺。
- 1950 庚寅（1.2，子丧）：庚劈甲（印伤）+ 寅为劫煞（集成第二十四节：巳酉丑见寅，"自外夺"）——儿子死于外部战争，"自外夺"精确。**辰时：流年庚直克时干甲，时柱子女宫受克，应期落点最准**；且辰时时支空，子女宫空亡与子女线重大丧失互证。
- 1966 丙午（1.5，文革）：丙夺丁光（滴天髓体用：劫财夺日主之光）+ 午冲子提纲——格局根基动摇之年天下大乱，合。
- 1971 辛亥（1.3，林彪事件）：辛财克甲（护法受损 = 权力结构震荡）+ 亥为驿马（奔亡），合。
- 1976 丙辰（1.7，逝世）：丙辰大运 + 丙辰流年，**岁运并临**；丙劫夺丁光。**辰时：流年辰与时柱辰伏吟 + 空亡填实，寿终于归宿之柱，最为贴切**；申时次之（申子辰杀局攻身）。

## 四、最终排序与把握度

**辰 > 申 > 巳 > 未 > 酉 > 寅 > 午 > 亥 > 戌 > 丑 > 卯 > 子**

### 第一名：辰时（把握度：高）
1. 格局最清：双甲夹丁、杀印相生相神两透，合横门"双柱同功"与穷通宝鉴子月丁"甲为尊"。
2. 应期四点精确：1934 甲戌、1958 戊戌两戌年冲辰应两次大迁移（长征/大跃进）；1950 庚寅克时干甲应子女宫之丧；1976 丙辰岁运并临 + 时柱伏吟、空亡填实应寿终。
3. 虚实互证：时支辰空 = 子女宫空（应子女线丧失）且为杀库空，星平会海"凶空则吉"，杀威收为我用。

### 第二名：申时（把握度：中）
1. 戊癸合杀为合杀清格，杀局有制合，贵格成立。
2. 时带亡神"自内失、机关不宁"，与 1971 林彪事件（最高权力结构内部震荡）高度同象。
3. 1976 丙辰申子辰杀局攻身可解寿终；但伤官合杀不及印化清纯，且戊在子月力弱。

### 第三名：巳时（把握度：低）
1. 乙印助化、巳劫帮身，全程喜忌方向一致，无刑冲破害，时支带天德。
2. "火空则发"，身弱者得根而不浊。
3. 缺独特精确应期命中，仅靠格局顺遂列第三，故把握度低。

## 五、余论

- 横门"三柱看"基线（第二十三章案例十五）：三柱已定"杀印相生、印为枢纽"之人，时柱只细化档次与应期——辰时正是在应期兑现上最容易兑现的立格（"取那个更加容易兑现就考虑那种情况"）。
- 与各流派交叉：调候（甲尊）、神煞（空亡虚实）、滴天髓（丙夺丁光应 1966/1976）、星平会海（凶空则吉）均指向同一方向，无流派间冲突。
