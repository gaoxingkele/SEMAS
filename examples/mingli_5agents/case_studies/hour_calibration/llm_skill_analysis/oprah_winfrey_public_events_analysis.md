# Oprah Winfrey（oprah_winfrey_public_events）时辰校准分析报告

- 分析方式：知识库技能驱动（横门主裁 + 调候 + 神煞/格局侧证），仅使用简报事件表与干支推理。
- 使用技能：mingli-bazi-hengmen（月令取格、成败救应、引动归时——主裁）、mingli-bazi-qiongtong-baojian（调候）、mingli-jicheng（神煞与特殊格局侧证）、mingli-bazi-sanming-tonghui（特殊格局同源佐证）、mingli-bazi-ditiansui（体用气势）。
- 防数据污染声明：**简报第 4 行印有公开参考时辰（寅时），分析全程未使用**，仅在本报告末尾事后核对。分析者对公开资料中该人物八字无任何记忆性使用。推理完全从「癸巳年、乙丑月、乙酉日」三柱 + 事件表出发。

## 一、三柱定盘（不依赖时柱即可确定的部分）

四柱公共部分：**癸巳（年）／乙丑（月）／乙酉（日）**，日主乙木，生于丑月（季冬）。

1. **月令取格（横门第十二章：用神专求月令）**：丑为杂气，藏己癸辛。生于大寒后约九日，己土司令而己不透；年干透癸——按人元司令「谁透用谁」，立**杂气偏印格**。
2. **支会金局**：年巳、月丑、日酉，**巳酉丑三合七杀局全**。金局成势，乙木坐酉为绝地，日主身弱，赖年干癸印化杀生身——**杀印相生**为主线（横门第十三章：印格透杀，「印轻逢杀」为成）。
3. **调候（穷通宝鉴）**：乙木丑月「**专用丙（寒谷回春）**」，且丙须通根寅巳午未戌支方为有力。冬木寒凝，火为第一喜神；原局唯年支巳中藏丙，且巳随金局有化金之虞，火根薄弱。
4. **综合喜忌**：喜火（调候+食伤暖局制杀）、次喜燥土（财）；忌金水再增寒、忌木根被冲。
5. **大运（阴女癸年顺行，约 2 岁起运）**：丙寅(2)→丁卯(12)→**戊辰(22,1976)**→**己巳(32,1986)**→庚午(42,1996)→辛未(52,2006)→壬申(62,2016)。**人生巅峰二十年（1986–2006）恰逢己巳、庚午南方火运**——命局喜火的铁证；事业大事全部落在火土运内，与时柱无关，这是三柱层面的硬约束。

### 前三名把握度与关键理由

**第 1 名 戌时（把握度：中）**
- 调候第一：丑月乙木「专用丙」，唯戌、子两时丙透干，而戌时丙火坐火库燥土、根气最实（穷通宝鉴调候表 + 通则「丙丁须临寅巳午未戌支方为有力」）。
- 职业十神最贴：伤官透时主口舌表达、公众传播与演艺曝光，与「电视主持人—全国脱口秀」主线严丝合缝；伤官又暖局制杀，一箭双雕。
- 引动归时命中两次高权重事件：1976 丙辰（入行）、1986 丙寅（全国开播，权重 1.3），丙皆为时干透字被流年直接引动。

**第 2 名 寅时（把握度：中）**
- 身有实根：寅藏甲丙戊，为乙木唯一真正强根候选，身弱杀重之局得此方能任财任杀；丙长生于寅，调候有暗根。
- 财富主线最贴：戊正财透时（时上正财），与「终身成就奖（1998 戊寅，恰为时柱伏吟）」「亿万富豪」的财星主线直接对应；戊癸遥合化火，财印相碍之病得解。
- 两次引动归时（1986 寅引动、1998 戊寅伏吟），权重合计 2.3。
- 减分项：寅巳刑（年时无恩之刑）。

**第 3 名 子时（把握度：中）**
- 引动归时命中最多（3 次：1976、1984、1986），天乙贵人归时（乙日子），伤官佩印主才华与文名。
- 未进前二的原因：丙火坐子水乡受克、子丑合绊（用神被合），且六乙鼠贵格因月支丑绊、日支酉填实而破格（《命理集成》卷二第十二節明载「忌午冲丑绊、申庚酉辛填实」），特殊格加分不得反见其绊。

### 事后核对（不参与上述推理）

简报所载公开参考时辰为**寅时**，本次知识驱动独立排序将其列为第 2 名（前三名之内）。简报所附确定性管线分数以巳时（0.6848）居首，本分析因「巳中丙火随巳酉丑金局化金、调候根被夺」将巳时降至第 4——此为知识推理与管线分数的主要分歧点，记录备查。
