## 一、三柱基线（12 时辰共有，先定人）

四柱共有部分：**戊戌年 庚申月 戊寅日**，日主戊土。

- **月令取格**（横门第十二章：八字用神专求月令）：申月庚金司令，庚透月干，
  **食神格**成立。食为四善神之一，顺用、保护性使用。
- **成格方向**（横门第十七章 食神格）：食神生财为上；身弱则弃食就煞印。
  年柱戊戌双土帮身、日支寅中藏戊丙甲，日主有根不弱，故主路线取**食神生财**。
- **破格之字**（横门第十二章"论用神成败救应"）：食神逢枭（丙偏印）为败；
  比劫争财为浊。
- **共有刑冲**：日支寅与月令申**寅申冲**，提纲冲日支，主一生根基动荡、
  迁徙无常（12 时辰均有，不区分候选）。
- **调候**（《穷通宝鉴》戊土申月条：先丙后癸；水多用甲泄之）：秋月土被金泄，
  需丙暖、癸润。丙与枭夺食相冲突，故最优解是**癸（壬）水润局而丙丁暗藏**。
- **气势流通**（《滴天髓·源流》）：局中最旺之神为月令庚申金（食神），
  源头在金；金生水则流通有情，"分其贵贱，全在收局一字定之"——
  **时柱是否见水（财）成为流通收局的关键变量**。
- **共有神煞**（《命理集成》神煞卷）：月支申 = 文昌（戊见申，聪明科名）+
  驿马（寅午戌马在申，迁动）；年支戌 = 华盖（寅午戌见戌，学艺孤高）；
  月令申在戊寅日甲戌旬中落空亡。文昌 + 驿马 + 华盖 + 食神格：
  走动的、孤高的艺术天才，人物底色吻合，但不区分时辰。

由事件表可得三条硬约束，用于时辰筛选：

1. **1982 壬戌（权重 1.4）**：原局须有壬（或癸）偏财/正财可被"同气引动"，
   且该字透干最佳——横门"引动=加强该字之象"（第二十三章）。
   → 时干透壬/癸者（戌、子、丑、亥）加分；干透支藏双引动者（戌）最优。
2. **1993 / 2005（权重合计 2.5）**：两起丑闻均为性指控主题 + 官非。
   命中须有"口舌/声色/官非"的标志位被酉年引动（伤官见官、桃花、子酉破、卯酉冲等）。
3. **2009 己丑（权重 1.6）**：时支宜与丑有刑合引动（刑动寿元根基），
   且原局劫财夺财路径须成立。

## 五、最终排序与结论

**排序（优 → 劣）**：
戌时 ＞ 子时 ＞ 丑时 ＞ 亥时 ＞ 卯时 ＞ 午时 ＞ 寅时 ＞ 酉时 ＞ 巳时 ＞ 未时 ＞ 申时 ＞ 辰时

### 第一名：戌时（把握度：高）

1. **格局成而清**：食神格配时干壬偏财，食神生财成格；壬水通根月令申中长生，
   "财气通门户"（《滴天髓·何知章》），源头（庚申金）→ 收局（壬财）流通有情。
2. **权重最高事件完美兑现**：1982 壬戌流年与时柱壬戌干支全同（横门"同位"，
   象互相连通；引动 = 加强该字之象），偏财大旺，正应 Thriller 历史性商业爆发
   （权重 1.4，全表最高）；财星落时柱，"引动归时"主中年后兑现，与实际
   （24 岁起巅峰）吻合。
3. **象意独家吻合**：年时双戌 = 双华盖（《命理集成》第九节：学艺、僧道、孤高），
   精准刻画孤绝的艺术家人格；寅戌拱午暗印，使申月戊土"先丙"之调候得暗解
   而不犯枭夺食之破——这是戌时对"调候需丙 vs 食神忌枭"这一结构矛盾的独家解法。

### 第二名：子时（把握度：中）

1. 同为食神生财成格，且申子半合财局，财最旺，商业成就有结构支撑。
2. **两次丑闻年均见子酉破**（1993 癸酉、2005 乙酉），财星逢破应于丑闻破财，
   事件对应密度为 12 时辰中最高之一；红艳煞（戊见子）侧应声色是非主题。
3. 不及戌时处：1982 年只得壬干单引动（无地支伏吟）；水偏旺欠甲泄，
   调候与身财平衡略逊。

### 第三名：丑时（把握度：中）

1. 食神生正财成格，癸水通根丑库，且癸透正合《穷通宝鉴》申月戊土"后癸"调候正字。
2. 天乙贵人在时（戊见丑），诸吉之首扶格。
3. 结构瑕疵：原局自带丑戌刑（年时相刑），1982 壬戌巅峰年引动刑字略损纯度；
   但 2009 己丑死年伏吟时支 + 丑戌刑重，应期解释力为 12 时辰中最直接，故仍居前三。
