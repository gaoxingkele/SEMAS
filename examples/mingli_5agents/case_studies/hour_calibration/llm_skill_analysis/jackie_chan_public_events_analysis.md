## 三柱定人（时柱未定前的共同底盘）

甲午 / 戊辰 / 癸巳，日主癸水生于辰月（水库、土旺之时）。

- **月令取格（横门第十二章）**：辰为杂气，本气戊土透于月干 → **杂气正官格**。
  官星即月令用神，为格局主线。
- **破格之字**：年干甲木伤官透，与月干戊土直接相克 → **伤官见官**，官格之病。
- **救应两路**（横门"论用神成败救应"）：
  1. 财通关——年支午火紧贴甲木，伤官生财、财生官（"化伤为财"式解救）；
  2. 印制伤——需庚辛透干制甲护官（"官逢伤而透印解之"），三柱无金，须时柱补给。
- **身弱基调**：癸水仅得辰中余气微根，日支巳为财官之乡，整体身弱，需印比扶身，
  或顺势论从（滴天髓"弱极从势"）。
- **调候（穷通宝鉴《论癸水》三月条）**：辰月癸水"专用辛，忌戊，要比劫滋甲制戊"。
  → 调候层面喜金（辛为上、庚次之）与比劫，忌戊土再透。
- **神煞底盘（命理集成，日/年为主）**：
  - 癸日天乙贵人在巳、卯（"壬癸兔蛇藏"）——日支巳已是贵人；
  - 甲午旬空亡在辰、巳——月令官星与日支财官均落空（各时辰共同项，不拉差距，
    唯时支再见辰者加重空象）；
  - 日支巳见月支辰之劫煞（"申子辰见巳"），主奔走利名——与动作影星职业气质相符。

三条稳定规律：

1. **两次最大突破（1978、1998，权重 1.3/1.4）皆在戊土正官透干年** → 正官确为
   "荣身"之物，正官格成立且官为喜用，伤官见官之病在原局必有制化（否则官年应灾不应吉）。
2. **两次名分/荣誉事件（1980 定型、2016 奥斯卡）皆在庚申、丙申——申金印星得地之年**
   → 印为喜，且"申"是高敏引动点。
3. **食神年（1985、1995）皆出里程碑** → 食伤泄秀为喜（表演输出），1995 兼驿马动象。

结论：命中喜用序为 **官（戊）＞ 印（庚辛/申）＞ 食伤吐秀**，财通关为佐；
时柱若能"补印扶身、制伤护官、或顺势成财生官之局"且不被冲破者为上。

## 最终排序（由优到劣）

1. **申时（庚申）** — 把握度：**高**
   - 横门最优救应：庚印透根制甲护官，"官逢伤而透印解之"，官印相生，格局最清；
   - 申辰拱水扶身，身弱得禄根，能任财官，与"官年荣身、印年得名"的事件规律全合；
   - 双事件直接引动归时：1980 庚申伏吟（定型）、2016 丙申动申（奥斯卡）；
     驿马归时应其国际奔走扬名之实。
2. **巳时（丁巳）** — 把握度：**中**
   - 财旺生官、伤官生财通关，与两次戊官年大突破完全同向；
   - 天乙贵人归时、日时双贵；1995 驿马冲巳而动，正应打入北美；
   - 短板：身弱极须假从财官解释，巳贵人带旬空，故列第二。
3. **午时（戊午）** — 把握度：**中**
   - 1978 戊午流年伏吟时柱，为全场最强单点"引动归时"（权重 1.3 事件）；
   - 官星戊癸合身、将星归时；
   - 短板：双戊争合日主为浊、午午自刑、调候忌戊再透，格局清纯度逊申巳。
